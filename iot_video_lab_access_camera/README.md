## How the System Works:
1. I used **Flask** to stream my webcam feed.
2. **ngrok** was used to expose the local server (`localhost:5000`) to the internet.
3. The stream was accessible using the ngrok URL from outside my local network.

## How the System Was Started:
1. On **Laptop A**, I ran the `app.py` file to start the local streaming server.
   ```bash
   python app.py
   ```
2. Then, I ran **ngrok** to expose the server:
   ```bash
   ngrok http 5000
   ```

## External Access:
- I successfully accessed the stream on another device (e.g., my phone) using the public URL generated by ngrok.
- The stream worked as expected from outside my Wi-Fi network.

## Problems Faced:
- **ngrok URL change**: The ngrok URL changes every time you run it. It was a bit inconvenient, but I was able to regenerate the URL each time I ran the server.
